# Calibration log

Tier-2 observations only. Hard preferences are edited directly into `../SKILL.md` and never logged here.

Format, one line per entry:

```
YYYY-MM-DD | what happened (user's words or observable behavior) | inference (preference or one-off?) | confidence (low/med/high) | occurrences
```

Rules: cap around 20 lines; delete from the lowest confidence up when over. Merge duplicates and increment the count. Delete any inference the user disowns. Promote to the spec when the same pattern appears in three different sessions, then strike those lines and note the promotion.
